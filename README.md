# Modernize your SQL Server estate with Azure SQL, AI and Fabric

This repository contains the materials, demos, hands-on labs, and deployment assets used in the Modernizing your SQL Estate workshop.

Learn how to modernize existing SQL Server workloads with Azure SQL, integrate operational data with Microsoft Fabric, and build AI-ready applications using modern data platform capabilities. Explore migration patterns, modernization strategies, analytics architectures, data integration scenarios, and practical examples that help you transform your SQL estate from on-premises databases to a cloud-connected, AI-powered data platform.

## Workshop Content

The workshop is divided into several modules, each focusing on a specific aspect of SQL databases in Microsoft Fabric. By the end of this workshop, you will have gained practical knowledge and hands-on experience in the following areas:

### 0. [Prerequisites](Workshop/Module%200%20-%20Prerequisites/README.md)

In this module, you will prepare for the workshop by reviewing the required technical knowledge, software, accounts, and connectivity. You will install and validate tools such as SQL Server Management Studio, Visual Studio Code, GitHub Copilot, Azure CLI, and the .NET SDK.

### 1. [Introduction and Setup](Workshop/Module%201%20-%20Introduction%20and%20Setup/README.md)

In this module, you will access the workshop environment, configure multi-factor authentication, and navigate the shared Azure dashboard. You will connect to SQL Server and Azure SQL Managed Instance and, optionally, validate GitHub Copilot in SQL Server Management Studio and Visual Studio Code.

### 2. [Migrate to Azure](Workshop/Module%202%20-%20Migrate%20to%20Azure/README.md)

In this module, you will explore a practical path for migrating an existing SQL Server workload to Azure SQL Managed Instance and learn how Azure supports SQL Server migration scenarios.

### 3. [Modernize in Azure](Workshop/Module%203%20-%20Modernize%20in%20Azure/README.md)

In this module, you will build on the migrated workload and explore how Azure capabilities can modernize your database environment, development workflow, and application architecture.

### 4. [Grow in Azure](Workshop/Module%204%20-%20Grow%20in%20Azure/README.md)

In this module, you will learn how to extend and grow your data estate in Azure, preparing your applications and operational data for new analytics and AI-driven scenarios.

### 5. [SQL in Fabric](Workshop/Module%205%20-%20SQL%20in%20Fabric/README.md)

In this module, you will work with SQL in Microsoft Fabric and apply its capabilities to the Zava digital assistant and customer support scenario, connecting operational data with analytics and AI-ready application patterns.
