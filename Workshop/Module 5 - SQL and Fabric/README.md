# SQL and Fabric

The purpose of this exercise is show you how to use SQL in Microsoft Fabric

## Steps

1. [Zava Digital Assistant and Customer Support App](<./Zava Digital Assistant and Customer Support App/README.md>) - Create a SQL database in Microsoft Fabric, connect the Zava banking app, and stream support requests to Fabric EventStream using Change Event Streaming (CES).
2. [Zava new insights through connected data sets](<./Zava new insights through connected data sets/README.md>) - Combine mission-critical Azure SQL data with Fabric applications using Lakehouse and Notebooks to derive decision-ready business insights.

> **Note:** Some resources in this section are shared across all attendees. The Fabric workspace (**SQLConBarcelonaWorkshop**), Azure OpenAI endpoint with deployed models (**foundry-zava-38e39j**) and the Fabric Eventstream (**ZavaEventStream01**) are shared. <br/>
Within that workspace, each attendee will create their own SQL database in Fabric, Lakehouse, and Notebook during the exercises.
