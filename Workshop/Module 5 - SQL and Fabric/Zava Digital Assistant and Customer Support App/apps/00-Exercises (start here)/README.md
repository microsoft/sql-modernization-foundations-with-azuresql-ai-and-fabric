# Exercises with Zava Digital Assistant and Customer Support Apps

In this workshop, you will create a SQL database in Microsoft Fabric and connect it to the Zava banking app. You will then enable **Change Event Streaming (CES)** and follow a customer support request from your database to the Zava Support app.

Azure OpenAI and Fabric Eventstream are already available for you. You will use the details supplied by your instructor to connect to them.

<img src="01%20-%20Getting%20Started/banking-app-high-level.png" width="800" />

## Learning Objectives

- Create SQL database in Microsoft Fabric workspace created for workshop.
- Run the banking app and explore the data it stores in SQL.
- Enable CES through Fabric's SQL query editor.
- See your support request arrive through Fabric Evenstream.
